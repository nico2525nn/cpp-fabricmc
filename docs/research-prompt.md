これは C++ で Minecraft Fabric 1.21.4 サーバーを非公式に実装・置き換えることを目的としたプロジェクトである。

現在、公式実装と比較して不足している機能は `docs/MISSING_FEATURES_1_21_4.md` の **Partial** および **Todo** に記載されている項目である。これらすべての項目について、**1項目ずつ個別に**、開発者向けの完全かつ詳細な技術レポートを作成すること。

各項目について、 `docs/MISSING_FEATURES_1_21_4.md` の対象項目番号を必ず含めること。

例として以下のような項目を各項目でリサーチして記述すること
* 機能概要
* 本家 Mojang および Fabric の実装仕様・アーキテクチャの詳細な分析
* 必要なクラス、データ構造、パケット、イベント、状態遷移の分析
* 実装フロー
* C++ 向けアーキテクチャ設計例
* クラス構成例
* モジュール分割例
* 実装時の注意点
* パフォーマンス上の考慮事項
* スレッドセーフティ上の考慮事項
* エッジケース
* テスト方法
* 実装優先度

本家実装を正確に分析するため、利用可能な限り **Web Search** および **Web Fetch** を用いて、公式・非公式を問わず十分な情報を収集・検証すること。時間や回答量に制限は設けず、完全性を最優先とする。

ファイル変更は以下以外行わないこと。

* 現在ある`plan/plan*.md`の数字を確認し、次の数字をxとする。
* `.gitignore` に `plan/` は既に追加済み（フォルダ一括無視）のため追加不要。
* 作成した技術レポートは `plan/planx.md` に記述する。

レポート内では、各章の冒頭で `docs/MISSING_FEATURES_1_21_4.md` のどの項目を対象としているかを明記すること。
